# Personal Portfolio Website

A modern and responsive personal portfolio website built using HTML, CSS, and JavaScript. The website features smooth animations, glassmorphism-inspired UI, responsive layouts, and a futuristic design aesthetic.

## Features
- Responsive Design
- Smooth Scroll Animations
- Modern UI/UX
- Glassmorphism Effects
- Interactive Hover Effects
- GitHub Pages Deployment

## Technologies Used
- HTML5
- CSS3
- JavaScript
